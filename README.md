# Приложение для прогнозирования цен акций

Учебный проект по прогнозированию временных рядов на примере цен акций.
Приложение запускается через Streamlit.

## Структура проекта

```text
TimeSeries/
├── frontend.py                                  # пользовательская часть приложения
├── backend.py                                   # загрузка данных, модели и прогноз
├── notebooks/
│   └── training_pipeline_auto_arima_stock_forecasting.ipynb # основной пайплайн обучения
├── models/
│   ├── AAPL_model.pkl
│   ├── AAPL_scaler.pkl
│   ├── AAPL_metadata.json
│   └── ...
├── requirements.txt
└── README.md
```

## Логика проекта

1. В основном ipynb-блокноте загружаются истории цен на акции из Yahoo Finance.
2. Для каждой интересующий компании ряд цен приводится к единому масштабу через
   `MinMaxScaler`.
3. Оптимальные параметры подбираются с помощью `pmdarima.auto_arima`.
4. Проверенные варианты модели сравниваются на контрольном отрезке по `MAE`,
   `RMSE`, `MAPE`, `AIC` и `BIC`.
5. Выбранная модель, scaler и сведения о модели сохраняются
   в папку `models/`.
6. Приложение Streamlit не обучает модель заново: оно загружает готовые файлы,
   получает свежие цены из Yahoo Finance и строит прогноз без повторной
   подгонки модели.

## Установка

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## Обучение моделей

Обучение модели происходит в среде Jupyter Notebook:

```text
notebooks/training_pipeline_auto_arima_stock_forecasting.ipynb
```

После выполнения в папке `models/` появятся:

- `*_model.pkl` - сохраненная модель для биржевого символа;
- `*_scaler.pkl` - преобразователь масштаба для корректной работы модели;
- `*_metadata.json` - параметры, метрики качества и сведения о модели;
- `auto_arima_model_results.csv` - таблица сравнения проверенных вариантов
  модели.

## Запуск приложения

```bash
streamlit run frontend.py
```

Обычно приложение откроется по адресу:

```text
http://localhost:8501
```

## Важно

Прогнозирование стоимости акций в этом проекте рассматривется только как учебный пример
прогнозирования временных рядов. Не является рекламой ценных бумаг. Не является индивидуальной инвестиционной рекомендацией и предложением финансовых инструментов.

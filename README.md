# Приложение для прогнозирования цен акций

Учебный проект по прогнозированию временных рядов на примере цен акций.
Приложение запускается через Streamlit. Отдельный сервер и отдельный
программный интерфейс не используются: пользовательская часть и модуль
расчётов находятся в одном проекте.

## Состав проекта

```text
TimeSeries/
├── frontend.py                                  # пользовательская часть приложения
├── backend.py                                   # загрузка данных, модели и прогноз
├── notebooks/
│   ├── training_pipeline_auto_arima_stock_forecasting.ipynb # основная последовательность обучения
│   └── training_pipeline_stock_forecasting.ipynb            # ручной подбор параметров для сравнения
├── models/
│   ├── AAPL_model.pkl
│   ├── AAPL_scaler.pkl
│   ├── AAPL_metadata.json
│   └── ...
├── requirements.txt
└── README.md
```

## Логика проекта

1. Обучающий блокнот загружает исторические цены из Yahoo Finance.
2. Для каждого биржевого символа ряд цен приводится к единому масштабу через
   `MinMaxScaler`.
3. В основном блокноте параметры подбираются с помощью `pmdarima.auto_arima`,
   как в теоретическом материале.
4. Проверенные варианты модели сравниваются на контрольном отрезке по `MAE`,
   `RMSE`, `MAPE`, `AIC` и `BIC`.
5. Выбранная модель, преобразователь масштаба и сведения о модели сохраняются
   в папку `models/`.
6. Приложение Streamlit не обучает модель заново: оно загружает готовые файлы,
   получает свежие цены из Yahoo Finance и строит прогноз без повторной
   подгонки модели.

## Установка

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## Обучение моделей

Основной вариант, близкий к теории:

```text
notebooks/training_pipeline_auto_arima_stock_forecasting.ipynb
```

После выполнения в папке `models/` появятся:

- `*_model.pkl` - сохраненная модель для биржевого символа;
- `*_scaler.pkl` - преобразователь масштаба для корректной работы модели;
- `*_metadata.json` - параметры, метрики качества и сведения о модели;
- `auto_arima_model_results.csv` - таблица сравнения проверенных вариантов
  модели.

Дополнительно оставлен блокнот `training_pipeline_stock_forecasting.ipynb` с
ручным перебором AR/MA/ARMA/ARIMA/SARIMAX. Он полезен как расширенный
исследовательский вариант, но студентам-новичкам проще начинать с
`auto_arima`.

## Запуск приложения

```bash
streamlit run frontend.py
```

Обычно приложение откроется по адресу:

```text
http://localhost:8501
```

## Важно

Прогноз цен акций в этом проекте используется только как учебный пример
прогнозирования временных рядов. Это не инвестиционная рекомендация.
